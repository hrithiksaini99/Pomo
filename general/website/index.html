Small app. Straight answers.

Is Pomo free?+

Yes. Pomo is free and open source under the MIT license. There’s no subscription, account, or paid feature tier.

Which Macs does it work on?+

Pomo requires macOS 13 Ventura or later. The source supports Apple silicon and Intel Macs. Release packaging can produce one universal app for both.

How do I install it today?+

The current release is a source preview. Build it on your Mac using Apple’s Command Line Tools and the four commands below. A signed installer will be published after Apple release signing is configured.

What happens when my Mac sleeps?+

A running timer includes time spent asleep. If it finishes during sleep, Pomo alerts you when your Mac wakes. A paused timer stays paused.

Can the stopwatch run with a focus session?+

Yes. They run independently. Pausing or stopping one does not affect the other, and both remain visible in your menu bar.

Does Pomo save or share my sessions?+

No. Pomo does not send data over the network or store a session history. The focus count and both timers reset when you quit the app.

A simple local install.

Install Apple’s Command Line Tools with xcode-select --install, then run:

git clone https://github.com/hrithiksaini99/Pomo.git
cd Pomo
./build.sh --install
open ~/Applications/Pomo.app

A notarized installer is the next release milestone.
No security settings need changing for a local build.
