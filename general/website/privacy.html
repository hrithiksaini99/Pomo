The Pomo app

Pomo does not make network requests, collect analytics, require an account, or send your focus sessions anywhere. Timer state and the focus count live in memory and clear when you quit. Pomo does not save a session history.

The app uses the macOS notification system for completion alerts if you allow them. macOS may retain delivered notifications until you clear them. Local diagnostic events, such as a started or finished preset, may appear in the macOS unified log. They do not contain personal documents or task content.

This website

This site has no analytics scripts, cookies, signup forms, or browser storage. Fonts and images are served from the same site. The interactive preview stays in your browser and resets when the page reloads.

GitHub Pages hosts this website. Its infrastructure processes requests, including connection information, under GitHub’s privacy statement. Links to GitHub take you to a separate service with its own policies.

Questions or changes

You can inspect the source code or open an issue. Avoid including private information in public issues.
